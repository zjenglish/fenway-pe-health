# Fenway PE and Health course site

Public course site for PE and Health at Fenway High School (Boston Public Schools), maintained by Zachary English.
Live: https://zjenglish.github.io/fenway-pe-health/

One static page (`index.html`), poster illustrations in `images/`, downloadable syllabi in `docs/`.
No student names, photos, or records. To update: edit `index.html`, then run `./deploy.sh`.
